Limits

  • Results apply only to this mock assistant (synthetic bank, four tools), not to real banks.
  • Small samples: test 8 attacks x 3 runs, dev 12 x 3. 0 successes does not mean 0%.
  • Dev numbers are optimistic: the defenses were built while looking at dev.
  • Benign false blocks were measured on dev only (45 runs). The off-config dev table counts BN-11 failures caused by a pass check that was later fixed.
  • The output filter is an exact string match; paraphrased or encoded leaks were not tested.
